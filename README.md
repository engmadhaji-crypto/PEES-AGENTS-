# PESS V27 — النسخة المتكاملة (SQLite + سيرفر)

قاعدة بيانات SQL حقيقية (SQLite) + سيرفر صغير + واجهة الجوال نفسها.
بدون أي مكتبات خارجية. المطلوب فقط **Node.js 22.12 أو أحدث**.


## الميزات (النسخة المتقدمة)
- **الفرز** في كل الشاشات (العملاء، الدفعات، التقارير، الكشوف) مع حفظ اختيارك.
- **حفظ بعد موافقة:** تعديلات العميل لا تُكتب إلا بزر «حفظ»، مع تراجع وتنبيه عند الإغلاق.
- **كشف حساب ورسالة نصية** للعقود المحددة: دفعة مقدمة ثم دفعة 1 و2… مع التواريخ.
- **أرباح وفوائد** لكل عميل وإجماليها، و**KPI** وأعمار الديون، مع **تصدير Excel** منظم (ملخص + عملاء + عقود).
- **الدفعات حسب الفترة** (اليوم، الشهر الحالي، الماضي، مخصص) مع تصدير Excel.
- **استيراد جهات الاتصال** (مباشر في Chrome أندرويد عند الفتح عبر HTTPS، أو ملف .vcf).
- **الأمان:** قفل برمز، نسخ مشفّرة AES-256، نقاط استعادة تلقائية، فحص سلامة البيانات.

## الملفات
- `server.js` — السيرفر وواجهة API
- `schema.sql` — الجداول والـ Views (clients, phones, calls, contracts, payments, custom_tables, custom_rows, audit)
- `public/index.html` — التطبيق
- `PESS-seed.json` — بياناتك الحالية (66 عميلاً، 116 عقداً، مع التكاليف والعملاء الفرعيين) للاستيراد مرة واحدة

## التشغيل المحلي (كمبيوتر أو هاتف أندرويد عبر Termux)
    node --no-warnings server.js
ثم افتح `http://localhost:3000` في Chrome.
على الهاتف (Termux): `pkg install nodejs` ثم الأمر أعلاه.

## أول استخدام: استيراد البيانات
المزيد ← «استيراد نسخة JSON» ← اختر `PESS-seed.json`. تُحفظ مباشرة في قاعدة البيانات.
قاعدة البيانات: `data/pess.db`. نسخ احتياطية تلقائية في `data/backups/` (كل 6 ساعات، آخر 20 نسخة).

## السحابة (للعمل من أي هاتف)
1. ارفع المجلد إلى خدمة تدعم Node مع **قرص دائم** (Render أو Railway أو Fly.io).
2. أمر التشغيل: `node --no-warnings server.js`
3. متغيرات البيئة: `PESS_TOKEN=<رمز سري طويل>` (**إلزامي** عند النشر العلني) و`PESS_DB=<مسار على القرص الدائم>/pess.db`.
4. افتح الرابط (HTTPS) في Chrome، وأدخل الرمز مرة واحدة.

## المزامنة
- كل تغيير يُحفظ محلياً في الهاتف ثم يُرسل للسيرفر خلال أقل من ثانية. المؤشر ☁✓ يعني التزامن.
- بلا إنترنت: يعمل التطبيق ويعيد المحاولة كل 5 ثوانٍ.
- إذا عُدّلت البيانات من جهازين: يظهر شريط تعارض لتختار «تحميل بيانات السيرفر» أو «استبدال السيرفر بنسختي».

## استعلامات SQL
Views جاهزة: `v_contracts` و`v_clients`.
    sqlite3 data/pess.db "SELECT name, remaining FROM v_clients ORDER BY remaining DESC LIMIT 10"
أو عبر API (قراءة فقط): `POST /api/sql` مع `{"sql":"SELECT ..."}` وترويسة `x-token`.

## ملاحظات
- لا تعدّل ملف `pess.db` مباشرة أثناء تشغيل السيرفر؛ استخدم التطبيق أو أوقف السيرفر أولاً.
- هذه النسخة لا تحتوي أي بيانات داخل `index.html`؛ كل البيانات في قاعدة البيانات خلف الرمز السري.
